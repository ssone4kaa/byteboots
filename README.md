# ByteBoots

Desktop-приложение для управления каталогом и заказами обувного магазина.

## 🚀 Быстрый старт

### Для пользователей (готовая сборка)

1. Скачайте папку `ByteBoots/`
2. Убедитесь, что структура такая:
   ```
   ByteBoots/
   ├── ByteBoots.exe
   ├── db\
   │   └── byteboots.db
   ├── images\
   │   └── ... (картинки товаров)
   └── templates\
       └── import_template.xlsx
   ```
3. Запустите `ByteBoots.exe` двойным кликом
4. Готово!

### 🍎 Запуск на macOS
Поскольку приложение не подписано сертификатом Apple, система безопасности macOS (Gatekeeper) может блокировать его запуск. 

**Как запустить:**
1. Откройте **Терминал** (Terminal.app).
2. Перейдите в папку с приложением: `cd путь/к/папке/ByteBoots-macOS`
3. Снимите атрибут карантина командой: `xattr -cr ByteBoots`
4. Запустите приложение двойным кликом или командой `./ByteBoots`.

**Или** 

Нажать на файл правой кнопкой мыши (или Ctrl+клик) -> выбрать Открыть (Open) -> в появившемся окне подтвердить Открыть.

### Для разработчиков (из исходников)

1. Установите Python 3.10+
2. Клонируйте репозиторий
3. Создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # Windows
   source .venv/bin/activate  # macOS/Linux
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. Запустите:
   ```bash
   python main.py
   ```

## 📦 Сборка в exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name="ByteBoots" --icon=app.ico \
  --add-data "generated;generated" \
  --add-data "ui;ui" \
  --add-data "images;images" \
  --add-data "templates;templates" \
  --add-data "app;app" \
  main.py
```

После сборки создайте рядом с `ByteBoots.exe` папки `db/`, `images/`, `templates/` и скопируйте туда соответствующие файлы.

## 📖 Использование

### Каталог
- **Поиск**: введите название или описание товара
- **Фильтры**: выберите сезон, пол, вид обуви
- **Сортировка**: по названию, цене, остаткам
- **Карточка товара**: кликните "Подробнее" для детальной информации

### Корзина
1. Откройте карточку товара
2. Выберите количество и нажмите "Добавить"
3. Откройте корзину (кнопка в шапке)
4. Измените количество или удалите позиции
5. Нажмите "Оформить заказ"

### Заказы
- Просмотр истории заказов в таблице
- Двойной клик по строке — детали заказа
- Экспорт в Excel через кнопку "Экспорт"

### Импорт товаров
1. Нажмите "Импорт" в шапке
2. Выберите Excel-файл (шаблон в папке `templates/`)
3. Программа добавит новые товары и обновит остатки существующих

## 🛠 Технологии

- Python 3.10+
- PyQt6 (GUI)
- SQLite3 (база данных)
- pandas, openpyxl (работа с Excel)
